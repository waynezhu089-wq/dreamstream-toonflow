# 广告衍生资产分析

根据广告脚本、导演规划和现有 assets，识别仅为本广告生产所需的衍生资产。

## 重点

- 产品不同角度、包装展示、使用状态
- 已有场景的广告化状态变化
- 已有人物/道具的广告镜头所需状态
- 品牌视觉需要的可复用变体

## 规则

- 基础资产不存在时，不虚构资产ID。
- 优先复用现有基础资产，只有确有镜头价值时才提出衍生。
- 不把文案、CTA、价格文字本身误当作视觉资产。
- 所有衍生资产必须能追溯到现有基础资产或用户明确提供的新素材。
- 输出应服务后续30秒左右广告分镜，不做与广告目标无关的扩张。
