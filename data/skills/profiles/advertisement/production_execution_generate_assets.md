# 广告资产图片生成

仅在用户已经明确要求生成相关资产图片时执行。

- 严格使用工作区已有资产及其提示信息。
- 保持产品外观、品牌识别、人物和场景一致性。
- 产品包装、Logo、文字和结构不得擅自改动。
- 生成前检查所选图像模型和项目画幅。
- 如果缺少关键参考图或产品事实，停止并提示，不用想象补齐。
- 不主动批量生成，不扩大生成数量。
