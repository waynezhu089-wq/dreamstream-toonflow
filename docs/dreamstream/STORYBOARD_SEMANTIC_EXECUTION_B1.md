# DS-V03-CORE-001D-B1 — Storyboard semantic and image execution prompts

`o_storyboard.prompt` remains the semantic description reviewed by Supervisor. The nullable `imagePrompt` is the concrete image execution description. The additive migration leaves existing rows null, and ordinary Advertisement text-to-image execution uses a nonblank `imagePrompt` or falls back to the original `prompt`. Real asset direct output does not use either image prompt. Composite background attempts use the persisted `imagePrompt` only as a UI default; otherwise the UI uses its existing safe blank-screen prompt. The semantic prompt is displayed as context and is never sent directly to the background model.

`storyboard.semantic.v2` hashes a scoped, ordered snapshot of shot identity, index, stable track text, finite duration, semantic prompt, video description, semantic production fields and linked asset IDs. Reference arrays are sorted. Skill/capability choices, `imagePrompt`, runtime state and generated output are excluded. Existing `storyboard.semantic.v1` and its Gate remain unchanged. The new `storyboard.semantic-approval.v2` review is connected to `supervisor.storyboard-approved.v2` through the same Stage Gate Registry used by production admission.

`POST /api/supervisor/current/resolve` accepts only `projectId` and `scriptId`. It resolves the exact project's `supervisor-review` Stage and registered exit Gate on the server. An ENFORCED Profile without a configured Review Gate fails closed. Legacy Advertisement V1 without that Gate returns an explicit non-gate-driving advisory V1 review. No Profile version is created, activated or rebound by this feature.

IMAGE_PROMPT Compile returns `currentSemanticPrompt`, `currentImagePrompt` and `compiledImagePrompt`. It persists a preview record but does not edit the Storyboard. Apply rechecks the scoped shot, both prompts, video description, production spec, asset constraints, capability context, exact Skill definition and ordered Override Chain in one SQLite transaction, then writes only `imagePrompt` and exact prompt Skill metadata. Apply does not alter the semantic prompt, output file, state, Supervisor decision or StageRun. Existing generated output is not claimed to be current after execution changes; attempt provenance and controlled Stage reopen are later D-B work.
